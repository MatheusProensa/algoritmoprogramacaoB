# Algoritmos e Programação B

Atividades da disciplina Algoritmos e Programação B — UFN.

## Atividades

### `atividade-telefonia/` — Aula 05/11

Programa em C++ que lê a base de sessões de telefonia, guarda os registros em um `vector` de `Telefone` e oferece um menu:

1. Listar telefones e mostrar a quantidade
2. Pesquisar por telefone e mostrar os dados de sessão
3. Finalizar

**Como rodar** (dentro da pasta `atividade-telefonia`):

```
g++ telefonia.cpp -o telefonia
./telefonia
```
